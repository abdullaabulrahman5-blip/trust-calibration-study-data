# Trust Calibration: Explanation and Accuracy Feedback

This repository contains anonymized data and supporting materials for the study on trust calibration in human–AI decision-making (Control vs Explanation vs Explanation + Feedback).

## Contents
- `data/Trust_Calibration_Responses.xlsx` : anonymized dataset (N = 300)
- `docs/data_dictionary.md` : variable definitions

## Notes on anonymization
The dataset contains no direct identifiers (no names, emails, phone numbers, or free-text responses). `ParticipantID` is an anonymized code.

## Reuse
Materials are provided for research and reproducibility purposes. Please cite the associated paper (citation will be added upon acceptance).
